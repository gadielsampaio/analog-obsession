# Design system

## Direction

The site is an editorial directory for Analog Obsession. It should point visitors to the creator's original releases and support channels without looking like a generic marketplace.

## Typography

- Shared interface/body: `IBM Plex Sans`
- Shared condensed headings: `Archivo Narrow`
- Technical metadata: `JetBrains Mono`
- Home hero display: `Oswald`
- Home hero body copy: `Inter`

Fonts are requested once in `BaseLayout.astro`; stylesheets do not import fonts independently.

## Palette

- Charcoal: `#141414`
- Off-white: `#e9e7e1`
- Tech red: `#d62828`
- Aluminum: `#8a8d91`

The CSS custom properties in `src/styles/global.css` are the source of truth.

## Component boundaries

Components exist where markup is genuinely repeated:

- `Header.astro`
- `Footer.astro`
- `CategoryHero.astro`
- `PluginCard.astro`
- `FaqItem.astro`

One-off Home sections remain in `index.astro` rather than being split into trivial wrapper components.

## Catalog data

Plugin content lives in `src/data/catalog.ts`. Each plugin stores identity, category, image, source URL and a generic `specs` list (`label` / `value`). This preserves category-specific metadata without hard-coding fields into the card component.

## Output

Astro renders static HTML. Category pages are generated by `src/pages/[category].astro`; the browser receives no framework runtime for the catalog.
